# Company Manager 媒体公司管理器插件

适用于酒馆助手 (TauriTraven/SillyTavern) 的浮窗式公司管理面板插件。

## 功能

### 首页
- 公司壁纸（支持本地图片上传）
- 公司名称编辑（点击标题即可修改）
- 账户余额显示
- 作品总数、累计收益、累计播放统计
- 快捷入口：作品库、推特发布、发布任务、添加作品

### 作品库
- 四分类：Coser写真集、短视频、小电影、ASMR
- 作品卡片网格展示（封面、标题、观看数、收益）
- 点击作品查看详情（描述、观看次数、收益、发布时间）
- 支持添加/编辑/删除作品，封面本地上传
- 作品详情可一键发布到推特

### 推特APP
- 四频道：短视频、小电影、音声、美图
- 推文流展示（头像、用户名、时间、内容、配图、点赞/转发）
- 支持手动发推（多图本地上传）
- 点赞、删除功能

### 发布任务
- 自定义任务要求（作品类型、详细描述、报酬）
- 发布后自动发送到聊天框，AI员工可投稿
- 投稿管理：发布（扣除报酬+同步到作品库）、收藏、拒绝
- 任务状态追踪（招募中/已收藏/已发布）

### 后端互动
- 所有数据存入角色变量（`cm_` 前缀），AI可读取
- 发布任务、添加作品、发推时自动将内容发送到酒馆聊天输入框
- 确保发送按钮可正常触发

## 安装方式

### 方式一：内联到角色卡（推荐，Tauri兼容）
将 `index.js` 完整内容作为脚本嵌入角色卡的 `data.extensions.tavern_helper.scripts` 数组中。

### 方式二：酒馆助手手动导入
1. 下载 `index.js`
2. 酒馆助手 → 脚本管理 → 角色脚本 → 导入
3. 选择该文件并启用

## 数据变量

| 变量名 | 说明 |
|--------|------|
| `cm_company_name` | 公司名称 |
| `cm_balance` | 账户余额 |
| `cm_wallpaper` | 首页壁纸(dataURL) |
| `cm_works` | 作品列表数组 |
| `cm_tweets` | 推文列表数组 |
| `cm_tasks` | 任务列表数组 |

## 兼容性
- 酒馆助手 Ver 4.8+ (Tauri桌面端/浏览器端)
- 适用于任意角色卡，不依赖特定扩展
- Shadow DOM 样式隔离，不影响页面其他元素
